# P3 ATM Keyboard Shortcuts Reference

## 🎹 Full Keyboard Navigation - No Mouse Needed!

### Welcome Screen
| Key | Action |
|-----|--------|
| `ENTER` | Enter PIN screen |

### PIN Entry Screen
| Key | Action |
|-----|--------|
| `0-9` | Enter digit |
| `ENTER` | Submit PIN |
| `BACKSPACE` | Delete last digit |
| `ESC` | Cancel and return to welcome |

### Main Menu
| Key | Action |
|-----|--------|
| `1` | Balance Inquiry |
| `2` | View Positions |
| `3` | Make Trade |
| `4` | Exit ATM |
| `ESC` | Exit ATM |

### Any Screen
| Key | Action |
|-----|--------|
| `ESC` | Go back to previous screen |
| `?` | Show keyboard shortcuts help |
| `H` | Show keyboard shortcuts help |

## 💡 Tips

- **No mouse needed!** All functionality is accessible via keyboard
- **Visual feedback:** Active elements are highlighted with an orange border
- **Keyboard indicator:** Look for the "⌨️ Keyboard Mode" badge in the bottom-right
- **Quick help:** Press `?` or `H` anytime to see the shortcuts overlay
- **Fast navigation:** Use number keys in the main menu for instant access

## 🔐 Example Workflow (Keyboard Only)

1. **Start ATM** - Press `ENTER` on welcome screen
2. **Enter PIN** - Type `0213` and press `ENTER`
3. **Check Balance** - Press `1` in main menu
4. **Go Back** - Press `ESC`
5. **View Positions** - Press `2`
6. **Go Back** - Press `ESC`
7. **Exit** - Press `4` or `ESC`

## 🚀 Shortcuts

### Quick Balance Check
```
ENTER → 0213 → ENTER → 1 → ESC → ESC
```

### Quick Position View
```
ENTER → 0213 → ENTER → 2 → ESC → ESC
```

### Emergency Exit
```
ESC (from any screen)
```

## 📝 Notes

- All keyboard shortcuts work immediately - no need to focus elements
- PIN entry is the only screen where number keys type digits
- On other screens, number keys are menu shortcuts
- The keyboard indicator badge is clickable to show help
- Console logs confirm keyboard navigation is active
